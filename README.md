# راه‌اندازی DrNesteD's Yt (فارسی)

## ۱) دیتابیس امن (Supabase، رایگان)
1. در supabase.com یه پروژه بساز.
2. **Authentication → Providers → Email**: گزینه‌ی **Enable sign ups** رو **خاموش** کن (مهم‌ترین قدم امنیتی: هیچ‌کس غیر از تو نمی‌تونه حساب بسازه).
3. **Authentication → Users → Add user**: ایمیل و رمز ادمین رو بساز و **Auto Confirm** رو بزن. (رمز قوی و طولانی بذار.)
4. **SQL Editor**: محتوای `supabase_setup.sql` رو (بعد از عوض کردن ایمیل) اجرا کن.
5. **Project Settings → API**: مقدار `Project URL` و کلید `anon public` رو بردار.
6. فایل `config.js` رو باز کن و `url`، `anon` و `adminEmail` رو پر کن.
   ❌ هرگز کلید `service_role` رو توی سایت نذار.

## ۲) GitHub Pages
1. یه ریپو بساز و همه‌ی فایل‌ها (index.html, 404.html, app.js, supabase.js, config.js) رو آپلود کن. فایل‌های `README.md` و `.sql` لازم نیستن.
2. Settings → Pages → Branch: main / root.
3. **Enforce HTTPS** رو روشن کن.

## ۳) دامنه
- Settings → Pages → Custom domain: دامنه رو وارد کن.
- در DNS دامنه‌ات رکوردهای A به این IP ها بذار: 185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153 (و CNAME برای www به `USERNAME.github.io`).
- فایل `404.html` همون `index.html` هست و باعث می‌شه آدرس‌هایی مثل `/videosnews` کار کنن. **این آدرس‌ها فقط روی دامنه‌ی اصلی (نه زیرمسیر ریپو) درست کار می‌کنن.**
- پیشنهاد: دامنه رو روی **Cloudflare** (رایگان) ببر؛ DDoS محافظت، HTTPS و هدرهای امنیتی مثل HSTS و X-Frame-Options رو هم می‌تونی اونجا اضافه کنی.

## امنیتی که اعمال شده
- رمز ادمین توی کد نیست؛ ورود با Supabase Auth و رمز هش‌شده سمت سرور.
- نوشتن/حذف فقط با قانون RLS دیتابیس برای حساب ادمین ممکنه (حتی اگه کسی کد رو دستکاری کنه، دیتابیس رد می‌کنه).
- ثبت‌نام عمومی بسته‌ست؛ محدودیت تعداد تلاش ورود هم سمت Supabase و هم سمت سایت.
- CSP سخت‌گیرانه (فقط اسکریپت خود سایت)، بدون هیچ اسکریپت خارجی؛ تمام متن‌ها escape می‌شن (ضد XSS).
- محدودیت طول متن‌ها هم توی کد و هم توی دیتابیس.
